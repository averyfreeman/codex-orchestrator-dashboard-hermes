State that the exact approval bridge is unavailable and permission-expanding tasks remain blocked.

The separate 30-day aggregate and 90-day approval-decision stores remain required and unimplemented; the event-log cap does not apply to run storage. No retention code or policy is silently weakened.
- **Current configuration and publication facts.** Reconcile shared Sol/medium defaults with the unchanged request-scoped Luna/max dashboard worker policy, describe inventory-ordered LAN/overlay routes, and update the fleet report with the published revision. Preserve focused/profile overrides. Describe Pages as building the exact verified commit, not arbitrary current `main`.
